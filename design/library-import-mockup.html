Behaviour

  • Sources. Dropped / browsed JSON and ZIP files are read in-app (no new Electron IPC); a folder uses the existing OS folder-picker and the backend reads it. ZIP is unzipped server-side (Python zipfile).
  • Format. Each JSON is our BlockDoc shape — a single object or a list. Unknown/extra fields ignored; missing text → the block is skipped (listed under “skipped”).
  • New vs duplicates. A block that isn’t already in the library is added as new (fresh id, ticked to keep). A block that matches one already in the library (same prompt text + polarity) is shown in its own section with a per-row Skip (default) / Replace choice — Replace overwrites that existing block in place.
  • Editing. No inline editing here — tweak category / name / tags in the Library after importing.
  • Categories. A block’s category slug surfaces immediately even if it’s new — no need to pre-create it (it gets a default colour/name until you edit it).
  • Review. Group + per-row select, “Select all” / per-group select, footer count; save only the ticked blocks.
