Presets tab + a sectioned Generate panel

A preset is a named bundle of generation parameters only — model, size, steps, guidance, sampler, quality toggle, UC preset, noise, rescale, image count. No prompt (that's the canvas), no seed (that's per-generation). The right-hand Generate panel becomes a set of collapsible sections so presets, the generated stack, and a draggable widget palette live beside the parameters.

Presets tab — anatomy

1
Built-in vs Your presets

Two groups. Built-ins (Anime, Curated, Fast draft, Wallpaper, Furry) ship read-only — duplicate to tweak, never delete. Your presets are user-owned, editable, deletable.

2
Preset card

Name · ★ favourite · one Default badge · model line · compact param chips (size + aspect glyph, steps, guidance, sampler). Hover reveals Apply / Edit / Duplicate / Delete.

3
Apply

“Apply” loads the preset’s params into the Generate panel and switches to Generate. The prompt on the canvas is untouched — only settings change.

4
Default

The ★ default preset seeds a new work’s params. Exactly one default; setting a new one clears the old. Built-in “Anime · Full” is the initial default.

5
Editor

“New preset” / “Edit” opens a drawer with the full param form (same controls as the panel) + a name. “Save current settings as preset…” from the panel prefills it from the live params.

6
Search

Filters by name across both groups. Flat list — no categories or tags (owner’s call); a preset library can grow one later if the list gets long.

Tools panel — tabs

Three tabs instead of one long scroll, so each area gets the full panel height — the Stack can actually show its contents.
1
Generation tab

All the parameters as today, with a Preset strip on top: the active preset, a modified dot when live params diverge, “Save as preset…” (captures current params) and “Update” (overwrites — user presets only). Seed is shown but labelled “not in presets”.

2
Stack tab

The full generated pile — newest first, count, Take-top / Download all / Clear, per-thumb Keep/Download on hover. Now that it owns a whole tab, it shows the actual contents. Drag a thumbnail onto the canvas to keep (same gesture as the station Output slot).

3
Widgets tab

A palette of draggable widget rows (Prompt blocks, Gallery — on canvas; Notes, Reference — new). Drag one onto the canvas to add that zone/widget; placed ones grey out. The home for the growing widget set.

4
Preset lives with Generation

The preset picker sits inside the Generation tab, not its own tab — a preset only touches generation params, so keeping them together avoids “apply here, see the effect there”.

5
Named “Tools”

Renamed from “Settings” (which clashed with the sidebar’s account Settings). The whole panel still collapses to the ⚙ rail; the active tab persists per session (layout).

6
Apply from Presets

Applying a preset from the Presets tab loads its params and switches to Generate on the Generation tab, with a toast.

Behavior rules

Preset = params onlyModel, size, steps, guidance, sampler, images, quality toggle, UC preset, noise, rescale. Never the prompt (canvas) or seed (per-generation).
Apply is one-wayApplying copies params into the live panel; later edits don’t write back unless you Update the preset. Editing params shows the “modified” dot vs the applied preset.
Built-ins are read-onlyShip as starters; Duplicate to customise. Can be set as Default and Applied, never edited or deleted.
Default seeds new worksA brand-new work starts from the default preset’s params. Exactly one default across built-in + user.
Stack ↔ canvasThe Stack section mirrors the station Output pile; dragging a thumbnail out materialises the image on the canvas (identical to today’s Output-slot drag).
Widgets are additiveDragging a widget tile drops that zone/widget onto the canvas; the Prompt-blocks and Gallery zones are the first two. Placed widgets grey out in the palette.
Panel = tabsGeneration / Stack / Widgets are tabs (not accordion) so each gets full height. The Preset picker lives atop the Generation tab. Active tab persists per session.
StoragePresets are small JSON in the vault (like Library blocks). Built-ins are code-shipped, merged read-only into the list.
Design locked — decision log
  • Preset = generation params only (no prompt, no seed). Flat list + code-shipped read-only built-ins; search, one Default, ★ favourites.
  • Presets tab: Apply loads params + switches to Generate (toast). Built-ins → Duplicate / “Save as new” only (never overwritten).
  • Right panel renamed Tools; three tabs — Generation (with the Preset strip on top) / Stack / Widgets; active tab persists per session; collapses to the ⚙ rail.
  • Stack tab and station Output slot coexist: the station keeps its slot for the live generating preview + top of stack (the generate flow); the Tools → Stack tab manages the whole pile (take / download / clear / drag-to-keep). Both are views over the same stack.
  • Widgets tab is the draggable palette for the growing widget set; placed widgets grey out.
