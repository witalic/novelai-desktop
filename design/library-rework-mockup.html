Library — aligned with the reworked widgets

The Library catches up to the canvas widgets: the title row is clean; search + Import/Export/New sit in their own toolbar; tag pins live under the search (no dropdown); blocks are grouped into category sections; pagination is a fixed bottom-right footer with a page picker; category management is consolidated into one modal; the block editor is a centered modal (with an examples toggle) reusable from the generation area; and Use is gone (the canvas widget browses the whole Library now).

Key decision baked in — confirm on review
  • Sections + infinite scroll: the list is sorted by category and loads more as you scroll, with a section header wherever the category changes. No pager. Filtering to one category shows just it.
  • One Export (toolbar dropdown, no duplicate in the selection bar): Selected · Current filter (everything matching category+tags+search) · Entire library. JSON (or ZIP) download.
  • Edit = centered modal with a Show examples toggle — the same component the generation area opens on “Save to Library”, so authoring never jumps you to the Library tab.

Anatomy

1
Clean title row

Just Library · N blocks. All actions moved out of the title, so the section header reads like the rest of the app.

2
Toolbar

Own row under the title: search on the left, and Import · Export ▾ · ＋ New block pushed to the right (data ops kept out of the search's way).

2b
Tag pins

Under the search, multi-select pins scoped to the active category (own scroll) — no dropdown, matching the canvas widgets.

3
Export scopes

Dropdown: selected · current filter (all pages) · entire library.

4
Selection bar

Appears when tiles are checked, aligned in the same gutter. Use is gone; actions are Move to category · Delete · Clear — all one button style. Export lives only in the toolbar (its dropdown covers “selected”), so there’s no duplicate.

5
Infinite scroll

No pager — the category-sorted list loads more as you scroll, so the footer never jumps. Section headers keep your place.

6
Consolidated category management

One ⚙ Manage modal: rename/recolor, delete, add, and restore defaults — all in one place (quick per-row ✎ still opens it focused).

7
Category sections

Blocks group under a category header (its own divider) instead of one flat canvas. Tiles drop the Use button — Edit · Delete only.

9
Centered edit modal

Replaces the side drawer. Show examples toggle; the same component the generation area opens on Save-to-Library, so authoring never leaves the current view.
